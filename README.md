# Social-Media-Engagement-Analysis

## Project Description
This project analyzes social media user engagement using Python and data visualization techniques.

## Objectives
- Compare posts by platform
- Analyze followers versus likes
- Compare engagement by content type
- Detect viral post outliers
- Visualize data using count plots, histograms, scatter plots, box plots, and violin plots

## Technologies Used
- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn
- Google Colab

## Dataset
Social_Media_Engagement_Dataset.xlsx

## How to Run

```bash
pip install -r requirements.txt
```

Open the notebook and run all cells.
